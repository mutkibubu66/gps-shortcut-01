The GPS's excuse, in its own voice, for sending the driver down the wrong road — one line for the [The GPS Swears It Was a Shortcut](https://make.fun/bounty/u-alven-the-gps-swears-it-was-a-shortcut-2cac21d9) bounty on make.fun.

## The line

> That dirt road WAS a shortcut — it just shortcuts straight into a lake, and the map never mentioned the lake part.

The GPS never admits it was wrong: the road really was shorter, it just ends in a lake — and somehow that missing detail is the map's fault, not the GPS's.

## Run it

```sh
python3 main.py
```

It validates the line (exactly one line, 1–200 characters, valid UTF-8, no leading or trailing whitespace) and writes it to `/output/entry.txt`.
