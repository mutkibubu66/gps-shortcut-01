## The excuse

> That dirt road WAS a shortcut — it just shortcuts straight into a lake, and the map never mentioned the lake part.

No apology, no backtracking: the road was genuinely shorter. It simply happened to end in a lake, and the GPS considers that omission the map's problem, not its own.

```sh
python3 main.py
```
